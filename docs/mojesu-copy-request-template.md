## How to write copy for this site

Use these rules on every section. Officials do not need to match word counts exactly — stay close so layout does not break.

| Element | Write like this | Avoid |
|---------|-----------------|-------|
| **Eyebrow** (small label above a title) | 1–4 words, title case or lowercase as brand prefers | Long sentences |
| **Headline / H1** | One clear promise; ~40–70 characters | Jargon stacks; unverifiable superlatives |
| **Title accent** (coloured part of a split headline) | 2–6 words that complete the sentence | Random keywords |
| **Body / intro** | 1–2 short sentences; concrete (Kampala, rent/buy/land, what Mojesu does) | “Lorem”, fluff, competitor digs |
| **Card title** | 3–6 words | Marketing slogans with no meaning |
| **Card / offering description** | 1–2 sentences; say the outcome for the client | Internal process jargon |
| **FAQ answer** | Direct answer first, then 1–2 supporting sentences | Soft “contact us for details” only |
| **CTA button** | Verb + object (“Request a visit”, “Get in touch”) | “Click here”, “Learn more” unless needed |
| **Stats / numbers** | Only publish figures you can defend (date + source) | Invented “180+”, “95%”, “premier” without proof |
| **Reviews** | Real client name (or initials + area), real role, real quote, real date | Fabricated testimonials (legal / trust risk) |
| **Agents** | Real staff only; real photo; real role | Stock faces / fake phones |
| **SEO title** | ~50–60 characters; include place + intent | Keyword stuffing |
| **SEO description** | ~140–160 characters; one benefit + one action | Duplicate the H1 |
| **Phone / WhatsApp** | One public phone policy: display format + digits for links | Mixing numbers without saying which is WhatsApp |
| **Addresses** | Exact line clients can visit or that Google Maps opens correctly | Placeholder roads |

**Claims policy:** Anything that appears on the site (including “verified”, “premier”, star ratings, home counts, recommendation %) must be true or removed. Google may surface FAQs and reviews as structured data.

**Photo policy:** Prefer owned Mojesu / client-consented photos. Stock Unsplash images are placeholders only. Provide JPG/WebP, landscape preferred for heroes (min ~1600px wide), square for agent/review avatars.
