# Insight template — citation-ready, Kampala-specific

Use in CMS → Insights → New. Blocks in this order:

| Block | Purpose | Rule |
| --- | --- | --- |
| **Title** | Primary phrase first | ≤ 51 chars, e.g. `Renting in Ntinda: What 2-Bedrooms Offer` |
| **Description** | Meta description | ≤ 155 chars, answers the query in one sentence |
| `lead` | Direct answer in 2–3 sentences | Quotable on its own (AI answers and snippets lift this) |
| `h2` + `p` / `list` | 3–5 sections, one question each | H2 phrased like a search: `How much deposit do Kampala landlords ask?` |
| links | Inside `p`/`list` text | `[3-bedroom houses in Kira](/rent/?location=Kira)` — see `internal-link-map.md` |
| `faq` | 3–5 real questions | Short factual answers; becomes FAQPage schema automatically |

## Evidence rules

- Prices or rents: only quote ranges visible on **our own live listings**, and
  say so ("Mojesu listings in Ntinda this month range from …").
- Legal/title process: describe what to verify, never promise an outcome; link
  `/services/surveying/`. Anything citing a law, fee or timeline → human verification.
- No invented statistics, yields, growth rates, "best"/"#1" claims or testimonials.

## Skeleton

```
lead: <direct answer, 2–3 sentences, mentions the area>
h2:   What you get for your budget in <Area>
p:    <facts from our listings> + [link to browse](/rent/?location=<Area>)
h2:   Getting around / what's nearby
p:    <verifiable, non-numeric local notes>
h2:   What to check before you pay
list: <checks> … [title verification](/services/surveying/)
faq:  <3–5 questions people actually ask agents>
```
